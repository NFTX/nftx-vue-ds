# Color System (Crimson-Wine Primary)

The `@nftx/vue-ds` color architecture establishes a deep crimson-wine primary brand palette (`rose-800` light, `rose-700` dark) strictly separated from error red (`red-600` light, `red-400` dark).

All ratios below are mathematically measured using the WCAG 2.2 relative-luminance formula and enforced automatically by `scripts/contrast-check.ts`.

---

## 2. Semantic Role Mapping

| Role | Light Theme | Dark Theme | Min Contrast Required |
| :--- | :--- | :--- | :--- |
| `brand-fill` + `on-brand` | `rose-800` + White (8.02:1, AAA) | `rose-700` + White (6.29:1, AA) | ≥ 4.5:1 (AA) / ≥ 7.0:1 (AAA) |
| `brand-text` | `rose-800` (8.02:1 on White, 7.66:1 on surface) | `rose-300` (9.44:1 on slate-900) | ≥ 7.0:1 (AAA) |

## 3. Brand vs. Error Perceptual Separation (ΔE)

To avoid confusing brand red with error red:
- **Light Theme Separation:** `rose-800` vs `red-600` achieves **ΔE(OKLab) = 13.8** (exceeds ≥ 10.0).
- **Dark Theme Separation:** `rose-300` vs `red-400` achieves **ΔE(OKLab) = 11.8** (exceeds ≥ 10.0).
