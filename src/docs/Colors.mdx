# Color System & Three Default Themes Architecture

`@nftx/vue-ds` delivers a resilient, mathematically verified three-theme color architecture out of the box:
1. **Light Mode (Default)**: Classical "Warm Paper" canvas (`#FAF8F5`) with "Print Ink Red" titling/accents (`#750008`) and deep charcoal body text (`#1E293B`).
2. **Dark Mode (Default)**: Luminous "Velvet Midpoint" oxblood canvas (`#3C0911`) with "Pale Champagne" gilded accents (`#FDE68A`) and "Warm Antique Ivory" body text (`#F7F4EE`) designed to eliminate glare and optical irradiation.
3. **Color Blind Mode (Default)**: Scientifically formulated Okabe-Ito Color Universal Design (CUD) palette built for the **"worst-case" scenario** across Protanopia, Deuteranopia, Tritanopia, and complete Achromatopsia (monochromacy).

All contrast ratios below are mathematically calculated using the WCAG 2.2 relative-luminance formula and continuously enforced by `scripts/contrast-check.ts`.

---

## 1. The Three Default Themes

### Light Mode: Warm Paper & Print Ink Red
Designed to evoke fine archival book typography and physical rubrication:
- **Canvas Base (`--ds-color-bg-base`)**: `#FAF8F5` (Archival warm paper / vellum)
- **Primary Brand (`--ds-color-brand-fill` / `--ds-color-brand-text`)**: `#750008` (**11.26:1 AAA** on paper, **11.93:1 AAA** on white)
- **Body Text (`--ds-color-text-primary`)**: `#1E293B` (**13.80:1 AAA** on paper)
- **Secondary Text (`--ds-color-text-secondary`)**: `#334155` (**9.77:1 AAA** on paper)
- **Error (`--ds-color-text-error`)**: `#DC2626` (4.56:1 AA vs paper, **ΔE = 23.4** separation from brand ink red)

### Dark Mode: Velvet Oxblood & Champagne Illumination
Eliminates eye fatigue and optical glare in low-light environments:
- **Canvas Base (`--ds-color-bg-base`)**: `#3C0911` (Velvet midpoint oxblood, relative luminance `0.0120`)
- **Brand Accents & Titling (`--ds-color-brand-text`)**: `#FDE68A` (**13.61:1 AAA** contrast on oxblood)
- **Primary Body Text (`--ds-color-text-primary`)**: `#F7F4EE` (**15.44:1 AAA** warm antique ivory — eliminates optical glare/irradiation caused by pure `#FFFFFF`)
- **Interactive Focus Ring (`--ds-color-focus-ring`)**: `#FDE68A` (**13.61:1 AAA**)
- **Error (`--ds-color-text-error`)**: `#F87171` (6.13:1 AA vs oxblood, **ΔE = 27.5** separation from champagne gold)

### Color Blind Mode: Okabe-Ito Universal CVD ("Worst-Case" Resilience)
A zero-compromise universal accessibility theme engineered for the **worst-case CVD scenarios**:
- **Why pure green and standard red fail**: In Protanopia (L-cone absent) and Deuteranopia (M-cone absent), red and green share identical visual pathways and collapse into muddy browns.
- **The Okabe-Ito Solution**: Replaces red/green collision pairs with **Deep Pure Cobalt Navy (`#003E7E`)** and **Luminous Amber/Honey (`#9A3412` / `#C26700`)**, paired with **Okabe-Ito Bluish-Green / Deep Pine Teal (`#004D40`)** for success states.
- **Achromatopsia Proof (Grayscale Luminance Stepping)**: For total monochromacy where hue is completely absent, every semantic state possesses a dedicated luminance tier (> 7:1 AAA everywhere). Even on a black-and-white display, no two functional elements share identical brightness!
- **Non-Color Redundant Cues**: Reinforced by 2px high-contrast structural borders, compulsory link underlines, and mandatory glyph icons (`check`, `alert-triangle`, `x-circle`, `info`).

## 3. Brand vs. Error Perceptual Separation (ΔE OKLab)

To guarantee that brand accents are never confused with error alerts, perceptual distance is verified via OKLab color space:
- **Light Theme**: Print Ink Red (`#750008`) vs Error Red (`#DC2626`) achieves **ΔE = 23.4** (requirement ≥ 10.0).
- **Dark Theme**: Pale Champagne (`#FDE68A`) vs Error Red (`#F87171`) achieves **ΔE = 27.5** (requirement ≥ 10.0).
- **Color Blind Theme**: Cobalt Navy (`#003E7E`) vs Rust Error (`#880000`) achieves **ΔE = 26.3** (requirement ≥ 10.0).

## 4. How Consumers Switch Between Themes

### HTML Attribute Switching
Any consumer application or web page switches themes by setting `data-theme` on `<html>` or any container:

```html
<!-- Light Mode (Default) -->
<html data-theme="light">

<!-- Dark Mode -->
<html data-theme="dark">

<!-- Color Blind Mode -->
<html data-theme="colorblind">
```

### Component-Level Switching with `DsHeaderBar`
`DsHeaderBar` supports cycling through all 3 default themes:

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { DsHeaderBar, type DsThemeMode } from '@nftx/vue-ds'

const activeTheme = ref<DsThemeMode>('light')
</script>

<template>
  <div :data-theme="activeTheme">
    <DsHeaderBar
      title="Homelab Portal"
      v-model:theme="activeTheme"
      :available-themes="['light', 'dark', 'colorblind']"
    />
  </div>
</template>
```

## 5. How Consumers Overwrite Theme Tokens

All styles in `@nftx/vue-ds` consume semantic CSS custom properties (`var(--ds-color-...)`). Consumers can override any individual token or entire themes at root, theme, or component scope without touching the library source:

```scss
/* Custom Light Mode Overwrite */
[data-theme='light'] {
  --ds-color-brand-fill: #9F1239; /* Custom crimson override */
  --ds-color-bg-base: #FFFFFF;     /* Pure white override */
}

/* Custom Company Brand Override */
[data-theme='corporate'] {
  --ds-color-brand-fill: #0052CC;
  --ds-color-bg-base: #F4F5F7;
  --ds-color-text-primary: #172B4D;
}
```

Interactive token auditioning and CVD simulation are available in Storybook under `Pages → EditorialBlogPostDemo` and `Pages → HomelabDashboardDemo`.
