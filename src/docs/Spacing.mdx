# Spacing & Touch Targets

The `@nftx/vue-ds` spacing system uses an 8-point base scale with a 4-point micro-step, defined entirely in `rem` units.

---

## 1. Spacing Scale

| Token | Rem | Px (at 16px root) | Usage |
| :--- | :--- | :--- | :--- |
| `--ds-space-1` | `0.25rem` | 4px | Hairline spacing, inline icon gaps |
| `--ds-space-2` | `0.5rem` | 8px | Compact padding, chip spacing |
| `--ds-space-3` | `0.75rem` | 12px | Form field gap, button vertical padding |
| `--ds-space-4` | `1rem` | 16px | Standard button horizontal padding, card padding (compact) |
| `--ds-space-5` | `1.25rem` | 20px | Moderate container padding |
| `--ds-space-6` | `1.5rem` | 24px | Card padding, stack spacing |
| `--ds-space-8` | `2rem` | 32px | Section gutters |
| `--ds-space-10` | `2.5rem` | 40px | Major component gaps |
| `--ds-space-12` | `3rem` | 48px | Modal margins |
| `--ds-space-16` | `4rem` | 64px | Page header spacing |

---

## 2. Touch Target Discipline (WCAG 2.2 SC 2.5.8)

Interactive components apply the `target-size` mixin to guarantee compliant physical hit areas:

- **Fine Pointer (Mouse, Trackpad):** Minimum `24px × 24px` (`1.5rem × 1.5rem`).
- **Coarse Pointer (Touchscreen, `@media (pointer: coarse)`):** Minimum `44px × 44px` (`2.75rem × 2.75rem`).

Visually compact elements (checkboxes, radio buttons, icon triggers) expand their hit area using a centered invisible `::before` pseudo-element without distorting visual layout.
